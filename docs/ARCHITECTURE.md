# 아키텍처

## 설계 철학

`.xlsx`는 사실 여러 XML 파일이 든 zip입니다. 이 앱은 SheetJS로 셀 값을 다시 쓰는 대신, **JSZip으로 원본 xlsx를 풀어 각 시트의 XML을 문자열로 직접 패치**한 뒤 다시 압축합니다. 이유는 단 하나 — 원작자가 오래 다듬어 온 수식·차트·조건부 서식·글꼴·병합·인쇄 설정을 **한 바이트도 건드리지 않기 위해서**입니다. 라이브러리로 다시 쓰면 이런 요소가 소리 없이 사라집니다.

따라서 코드 전반은 "정규식으로 특정 셀/행을 찾아 안쪽만 교체"하는 패턴으로 이루어져 있습니다.

## 처리 파이프라인

```
[원본 .xls 7개]            [지난달 마스터 .xlsx]
      │                          │
   readXls (SheetJS)         initTemplate (JSZip 해체)
      │                          │
   store[cat] = rows        resolveSheets → 시트별 XML
      │                          │
      └──────────┬───────────────┘
                 ▼
            generate()
                 │
   ┌─────────────┼───────────────┬────────────────┬─────────────┐
   ▼             ▼               ▼                ▼             ▼
buildMonth   reshapeIlbyul   rollBiyul      appendMulti…   캐시 주입
(일자별 집계) (일별 시트 재구성) (비율누적/통계)  (multi 시트)   (withCache)
                 │
                 ▼
        patchWorkbook → JSZip 재압축 → 다운로드
```

## 주요 함수 지도

### 입력 처리
- **`classify(filename)`** — 파일명으로 7개 카테고리(정규/추가/응급약/응급실퇴원약/퇴원약/외박약/마약) 판별
- **`readXls`** — SheetJS로 `.xls` → 행 배열. 헤더의 별표(`*`)·공백 정규화
- **`ingest` / `renderIntake`** — 드롭된 파일 수집·화면 표시
- **`detectMonth`** — 원본 집계일자에서 대상 연·월 자동 감지

### 마스터 해체
- **`initTemplate`** — 업로드된 마스터를 JSZip으로 풀기
- **`resolveSheets`** — workbook.xml + rels로 시트명 → XML 파일 매핑
- **`parseSharedStrings`** — 공유 문자열 테이블 파싱

### 일별 시트
- **`buildMonth(y,m)`** — 날짜별로 7개 store를 집계해 `days[]` 생성. 시간대 매핑, 주·야간 분리, 비근무일 09시·15시 0 처리, 날짜 색상 카테고리(`cat`) 부여
- **`detectCapacity`** — 마스터의 기존 데이터 행 수 감지(SUM 수식 위치 기준). 30↔31일 차이 흡수
- **`reshapeIlbyul`** — 일자 행을 새로 깔고 값 채움. 합계·평균 행, AA 행합계 재배치. 행 삽입/삭제에 따른 참조 이동 처리
- **`harvestColors`** — 원본에서 토/일/평일 셀 스타일 인덱스를 수확(색상 서식 재사용용)

### 비율 누적 / 통계파일용
- **`rollBiyul`** — 핵심. 원작자의 "선준비 블록 활성화" 방식 재현. 직전 완전 블록 F열 값 동결, 이번 달 블록 활성화(증감률 I열 14행 전부 수식), 다음 달 블록 선준비. 통계파일용 D열 전진 + 캐시. → 상세는 [`DERIVATION_RULES.md`](DERIVATION_RULES.md)
- **`readPrevStatsF`** — 마스터 일별 F열에서 이번 달 기준 통계값 회수(수동 입력 야간외래 자동 반영)
- **`monthlyStats`** — 이번 달 14개 지표의 일평균 계산
- **`rollTable`** — 12개월 롤링 표(아래→위 한 칸 이동, 맨 아래 라이브 행 유지)

### multi 시트
- **`appendMultiWeekend`** — 주말(금·토·일) 블록 A~H + J~V 12개월 추이표 생성
- **`appendMultiChart`** — 전월 차트 복제. 범위 참조 이동, 계열 GUID·앵커 creationId 재생성, 전용 colors/style 파트 생성(Excel 복구 삭제 방지)

### XML 유틸
- **`setCell` / `withCache`** — 셀 교체 / 수식 셀에 캐시값 주입
- **`emitCell`** — 행 재구성 시 셀 방출(수식 이동 + 캐시 보존)
- **`shiftRefs`** — 수식 내 행 참조를 delta만큼 이동
- **`cellRaw` / `cellVstr` / `styleOf` / `styleAttr`** — 셀 원문/캐시값/스타일 추출
- **`inlineStr` / `esc` / `unesc`** — 인라인 문자열 처리·이스케이프

### 공휴일
- **`loadHolidays(y)`** — date.nager.at에서 연도별 한국 공휴일 로드(실패 시 빈 세트로 폴백). Public 타입만 필터
- **`isHoliday(y,m,d)`** — 해당 날짜 공휴일 여부
- **`nonWorkingDays(y,m)`** — 비근무일 집합(토·일 + 15시 추가 ≤5건인 날)
- **`renderNonwork`** — 주말·공휴일 칩 렌더(공휴일이면 토요일도 빨강)

## 캐시 주입이 필요한 이유

엑셀 수식 셀은 `<f>수식</f><v>캐시값</v>` 구조입니다. 캐시값이 없으면 파일을 재계산 없이 미리 볼 때(보호된 보기, 파일 탐색기 미리보기 등) 빈칸으로 보입니다. 그래서 생성 시 모든 수식 셀에 계산 결과를 캐시로 넣습니다. 실제 엑셀에서 열면 자동 재계산으로 덮어써지므로 정확도에는 영향이 없고, "열어보니 값이 비어 있다"는 오해만 방지합니다.

핵심 교훈: 원본 마스터 자체가 **일부 셀에서 "빈 셀을 가리키는 수식 + 옛 캐시값"** 상태였습니다. 화면엔 숫자가 보이지만 재계산하면 0이 되는 상태였고, 이를 원작자의 초기(정상) 방식대로 **증감률 수식을 14행 전부에 넣어** 재계산 후에도 값이 살아남도록 고쳤습니다(v2.7).

## 검증 방식

개발 중에는 Node 하네스로 3개월(3·4·5월)을 교차 생성해, 생성 결과를 원본 마스터와 셀 단위(스타일·수식·값·라벨)로 대조했습니다. 남는 차이는 (1) 수동 입력 대상인 야간외래 2칸, (2) 열면 재계산으로 동일해지는 캐시값 차이뿐임을 확인했습니다. zip 무결성, XML well-formed, 차트 creationId 중복 0, 범위 참조 깨짐 0도 매 회 검증했습니다.
