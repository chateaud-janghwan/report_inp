# 파생 규칙 (역공학 + 3개월 교차검증)

원본 마스터에는 문서가 없었습니다. 아래 규칙은 3·4·5월 원본 파일을 셀 단위로 분석해 확정하고, 생성 결과를 원본과 대조해 검증한 것입니다.

## 일별 시트

### 시간대 → 열 매핑
- `HOURS = [08,09,10,11,12,14,15,16,18,20,22,24]시` → D~O열
- P열 = 다음날 06시 추가
- Q/R = 응급약 주간/야간, S/T = 퇴원약 주간/야간, U/V = 응급실퇴원약(주간은 비근무일만)/야간
- W/X = 외박약 주간/야간, Y = 마약, Z = 야간외래(수동 입력)

### 비근무일 처리
- 비근무일 = 토·일 **또는** 그날 15시 추가 건수 ≤ 5건(외래 연동 시간대라, 외래 없는 날의 자투리 오입력을 걸러냄)
- 비근무일은 E열(09시)·J열(15시)을 **강제 0** 처리 → 원작자도 동일하게 처리해 왔음을 raw 대조로 확인
- U열(주간 응급실퇴원)은 비근무일에만 집계

### 날짜 색상 (v3.1)
- 우선순위: **공휴일 → 빨강** > 토요일 → 파랑 > 일요일/감지 비근무일 → 빨강 > 평일 → 검정
- 즉 토요일과 겹친 공휴일(예: 2026-06-06 현충일)은 빨강. 스타일 인덱스는 원본에서 수확한 일요일 서식을 재사용

## 비율 누적 시트 (핵심)

원본은 12개월 누적 통계를 **세로로 쌓인 블록**들로 관리합니다. 각 블록은 헤더 1행 + 지표 14행 구조입니다.

### 블록 상태 3종
1. **동결 블록** — 지나간 달. F열이 값으로 고정됨(라이브 수식 아님)
2. **활성 블록** — 이번 달. C열=지난달 기준값, F열=`일별!F…` 라이브 참조, I열=증감률 수식
3. **선준비 블록** — 다음 달치를 미리 깔아둠. 활성 블록을 17행 아래로 복사한 형태

### 롤링 절차 (`rollBiyul`)
1. **선준비 감지** — 마지막 블록 헤더의 C 라벨이 "지난달"이면 이미 선준비된 상태(라벨 기반 감지)
2. **직전 완전 블록 동결** — F열을 캐시값으로 고정. 동결 안 된 옛 블록은 라이브 수식이 행 이동에 따라 자동 이동(원본과 동일)
3. **활성화** — 선준비 블록을 이번 달 블록으로 승격:
   - 행 속성 보존(`spans="2:9"`), 기존 B/E/H 셀과 C/F 스타일 유지
   - C열 = 마스터 일별 F열 기준값(수동 입력 야간외래 자동 반영)
   - F열 = `일별!F{18+N+i}` (N=이번 달 일수), 캐시=이번 달 통계
   - **I열(증감률) = `((F/C)-1)` 수식을 14행 전부에** (v2.7에서 3행→14행으로 복원)
4. **선준비** — 다음 달 블록을 17행 아래에 복사 생성. 라벨·스타일을 방금 활성화한 블록에서 복제

### 증감률(I열) 규칙 — v2.7 변경
- **초기(정상) 방식**: I열 14행 전부에 `((F/C)-1)` 수식
- 원본 4월 이후 파일은 일부만 수식이고 나머지는 "빈 셀 참조 + 옛 캐시"로 망가져 있었음(수동 계산 상태라 안 들켰음)
- v2.7에서 원작자 초기 방식대로 **14행 전부 수식**으로 복원 → 재계산해도 값이 살아남음
- 검증: 원본이 화면에 보여주던 값(정규 +1.0%, 총매수 +3.0% 등 13/14)과 정확히 일치. 야간외래만 원본 데이터 없어 -100%(수동 입력 후 정상화)

## 통계파일용 시트

- D3~D16 = `'비율 누적'!I…` 참조로, 이번 달 새 활성 블록의 I열을 가리키도록 전진
- B열·C열 = 이번 달 통계(총합·일평균), 캐시 주입
- v2.7에서 D열 캐시도 활성 블록 기준으로 계산해 채움

## multi 시트

### 주말 블록 (A~H)
- 금·토·일 3일 묶음. n≥3이면 C/E/G 3열 + D(=C/H)·F(=E/H) 비율, n=2면 C/G + D 비율
- H = 합계 수식, 각 셀에 계산 캐시 주입

### J~V 12개월 추이표
- 토요일 평균(D), 일요일 평균(D·F), 공휴일 평균 등을 AVERAGE 수식 + 평균 캐시로 생성
- 매달 K~U를 전월 L~V 캐시값에서 굴리고, V열은 라이브 AVERAGE + 계산 캐시

### 차트 복제 (`appendMultiChart`)
- 전월 차트를 복제해 새 chartN 생성
- `multi!` 포함 `<c:f>` 범위의 행 참조를 양끝 모두 +delta 이동(초기 버그: 시작만 이동 → 수정)
- 계열 uniqueId GUID·앵커 creationId 재생성(**중복 시 Excel이 차트를 복구하며 삭제** → 차트 안 그려지던 근본 원인)
- 차트별 **전용 colors/style 파트** 생성 + `[Content_Types]` Override 등록(공유 시 복구 유발)
