# report_inp — 병동조제실 업무현황 파일 생성기

지난달 업무현황 마스터(`.xlsx`) 하나와 이번 달 원본 처방 집계 파일 7개(`.xls`)를 넣으면, 이번 달 업무현황 마스터를 자동으로 완성해 주는 **100% 클라이언트 사이드** 웹앱입니다. 서버·백엔드·빌드 과정이 전혀 없고, `index.html` 파일 하나가 전부입니다.

핵심 원칙은 **"데이터만 바꾸고 나머지는 원본 그대로"** 입니다. 원본 마스터의 수식·차트·글꼴·셀 스타일·시트 구조를 한 톨도 훼손하지 않고, 숫자가 들어가는 칸만 새 달 값으로 교체합니다.

현재 버전: **v3.5**

---

## 무엇을 해 주나

- **일별 시트**: 새 달의 날짜 행(30일/31일 자동 대응)을 다시 깔고, 원본 7개 파일에서 집계한 처방 건수를 시간대별로 채웁니다. 합계·평균 행과 AA열 행합계 수식까지 정상 작동하도록 캐시를 넣습니다.
- **비율 누적 시트**: 원작자의 "다음 달 블록 선준비 → 이번 달에 활성화" 방식을 그대로 재현해, 12개월 누적 블록을 한 칸 굴리고 직전 달 블록을 값으로 동결합니다.
- **통계파일용 시트**: 전월대비 증감률(D열)을 새로 활성화된 블록으로 전진시키고, 열자마자 값이 보이도록 캐시를 채웁니다.
- **multi 시트**: 주말(금·토·일) 블록과 J~V 12개월 추이표를 다시 만들고, 전월 차트를 복제해 이번 달 범위로 옮깁니다.
- **주말·공휴일 표시**: 한국 공휴일 캘린더(외부 API)를 참조해, 토요일과 겹친 공휴일도 빨간색으로 표시합니다(웹 칩 + 엑셀 일별 시트 양쪽).

## 사용법

1. `index.html`을 브라우저에서 엽니다(로컬 더블클릭도 되고, 배포된 사이트도 동일).
2. **1단계** — 지난달 업무현황 `.xlsx`를 올립니다. (예: 6월을 만들려면 5월 마스터)
3. **2단계** — 이번 달 원본 7개(`정규`, `추가`, `응급약`, `응급실퇴원약`, `퇴원약`, `외박약`, `마약`)를 드롭합니다. 파일명으로 자동 분류됩니다.
4. 감지된 대상 연월과 주말·공휴일 칩을 확인합니다.
5. **생성** 버튼을 누르면 완성된 `업무현황_YYYYMM.xlsx`가 내려받아집니다.
6. 엑셀에서 열면 일별·차트·전월대비·12개월 추이가 자동 계산됩니다.

### 자체검증 로그 (v3.4~)

생성 직전에 결과물을 규칙으로 훑어 이상 징후를 로그에 남깁니다. **경고가 떠도 파일은 그대로 만들어집니다** — 오탐 때문에 업무가 멈추지 않도록 한 의도적인 선택이니, 경고가 보이면 해당 항목만 엑셀에서 눈으로 확인하세요.

검사 항목:

- 차트가 물고 있는 일별 일자 범위가 `4~(3+일수)`행인지 — 합계행 혼입, 마지막 날 누락 탐지
- `[Content_Types].xml` 등록 누락, 없는 파트를 가리키는 관계 — 엑셀 "복구가 필요합니다" 대화상자의 주범
- 일별 시트의 첫날·마지막날 날짜, 합계행에 날짜가 남아있지 않은지
- 14개 항목의 전월 대비 ±50% 초과 — 원본 7개 중 하나가 빠졌거나 잘못 분류되면 여기서 잡힙니다
- multi 12개월 추이표의 이번 달 칸(V열) 공란 여부

> 검증은 전부 브라우저 안에서 규칙으로만 돌아갑니다. 외부로 나가는 데이터가 없습니다.

> **연쇄 생성**: 4월을 만들 땐 3월 마스터 + 4월 원본, 5월을 만들 땐 방금 만든 4월 결과를 마스터로 삼습니다.

### 야간외래 입력

야간외래(일별 시트 Z열)는 원본 집계 파일이 없어 자동으로 채워지지 않습니다. 생성 후 일별 시트 Z열에 야간외래 건수를 직접 입력하고 저장하면, 아래로 연결된 비율누적·통계 값이 전부 수식으로 자동 반영됩니다. 다음 달 생성 시 이 값이 기준선으로 자동 계승됩니다.

## 배포 (Cloudflare Pages / Workers)

이 저장소는 GitHub에 연결되어 있고, `main` 브랜치에 푸시하면 Cloudflare가 자동 배포합니다.

- **GitHub**: `chateaud-janghwan/report_inp`
- **배포 확인**: 사이트 제목 옆의 버전 표시(`v3.5`)와 생성 로그 첫 줄의 `(앱 vX.X)` 로 현재 버전을 확인합니다.
- **캐시 주의**: 배포 후에도 옛 화면이 보이면 강력 새로고침(Ctrl+Shift+R) 또는 시크릿 창으로 확인하세요.

자세한 내용은 [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) 참고.

## 기술 스택

- 순수 HTML/CSS/바닐라 JS (프레임워크·빌드 없음)
- [SheetJS(xlsx)](https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js) — 원본 `.xls` 읽기
- [JSZip](https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js) — `.xlsx`(zip) 해체·재조립
- [Pretendard](https://cdn.jsdelivr.net/gh/orioncactus/pretendard) — 글꼴
- [date.nager.at](https://date.nager.at) — 한국 공휴일 캘린더 API(키 불요, CORS 허용)

> `.xlsx` 편집은 라이브러리에 맡기지 않고 **XML을 직접 문자열 패치**합니다. 원본의 수식/차트/스타일을 바이트 수준으로 보존하기 위한 의도적 선택입니다.
